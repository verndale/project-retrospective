# Source-parity capture contract

## Summary

Require every future component capture to inventory reusable source behavior, visual layout, and invariants before normalized code and Figma can be considered complete.

## Implementation

- Record the exact Git revision during inventory and grade unrecoverable legacy provenance explicitly.
- Add one deterministic source-parity companion per capture with safe hashed citations, complete surface coverage, closed difference classifications, and review state.
- Reuse the companion validator from the sanctioned report validator and advance capture preflight to schema v5.
- Extend automatic tracking for one contract/audit/governance foundation issue and per-component remediation only when actionable.
- Update the skill workflow, references, operator documentation, synthetic fixtures, tests, and context wiki together.

## Validation

- Exercise valid, missing, orphaned, malformed, and unsafe source-parity artifacts through the real CLI.
- Run the complete project-retrospective test and graph gates.

## Boundaries

- Preserve historical run files.
- Keep client-derived evidence outside this public repository.
- Do not commit, push, open a pull request, close issues, publish Figma, merge, or release without explicit maintainer authorization.
